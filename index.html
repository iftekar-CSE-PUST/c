Privacy Policy

1. Data Storage

All student data is stored securely in Supabase cloud database. No data is stored in the browser code or local files.

2. Authentication

Login credentials are verified against the database. Passwords are not stored in the HTML code. Session tokens are stored in browser sessionStorage and cleared on logout.

3. Data Access

Student information is only accessible to authenticated users. Data is fetched live from the database on each session.

4. Security Measures

  • Rate limiting on login attempts (5 attempts max)
  • No hardcoded passwords in source code
  • All data served from Supabase with Row Level Security
  • Session expires on browser close

5. Third-Party Services

  • Supabase (Database & Auth)
  • Font Awesome icons
  • Google Fonts

6. Your Rights

You can logout at any time to clear session data. Contact the admin to update or remove your information.
